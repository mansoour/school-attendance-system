# Arabic Laravel SaaS Starter Kit

نقطة بداية مستقلة لبناء تطبيقات SaaS بالعربية والإنجليزية باستخدام Laravel، مع واجهات من اليمين إلى اليسار، وإدارة الحسابات والصلاحيات والترجمات وهوية الموقع والباقات الاختيارية.

[English](README.md) · [الإعدادات](docs/CONFIGURATION.md) · [التكاملات](docs/INTEGRATIONS.md) · [النشر والنسخ الاحتياطي](docs/DEPLOYMENT.md)

## المزايا

- واجهات عربية وإنجليزية، واتجاه RTL، وأسهم متوافقة مع اتجاه اللغة، وخط IBM Plex Sans Arabic مستضاف محليًا.
- التسجيل والتحقق من البريد واستعادة كلمة المرور وإدارة الحساب، مع مصادقة ثنائية اختيارية ورموز استرداد.
- لوحة إدارة بصلاحيات مفصّلة، وإضافة الأدوار وتعديلها وحذفها، مع حماية دور مالك الموقع.
- قائمة جانبية مقسّمة بمسار تمرير مستقل، وشريط تنقل بعرض كامل يتضمن الحساب واللغة والمظهر والإشعارات.
- باقات واشتراكات يدوية وحدود استخدام اختيارية؛ الباقات معطّلة افتراضيًا.
- تخصيص الأسماء والشعارات والأيقونات والألوان والخطوط وروابط التواصل وإشعار ملفات الارتباط.
- محرر ترجمة للعبارات يدعم المسودات والمعاينة والنشر وإدارة ظهور اللغات.
- صفحات Markdown، وإشعارات الموقع، وقوالب البريد، وصندوق الدعم، وسجل النشاط وفحوص حالة النظام.
- إعدادات Resend وGemini وreCAPTCHA وCloudflare R2، مع تخزين مفاتيح التكامل مشفّرة.
- طوابير للمهام، وجدولة، ونسخ احتياطية تدعم تشفير AES-256 عند إعداد كلمة مرور الأرشيف.

المشروع أساس قابل للتخصيص. لا يتضمن بوابة دفع أو فواتير أو عزلًا بين المستأجرين أو إجراءات خاصة بمنتج محدد.

## المتطلبات

PHP بإصدار 8.3 أو أحدث، وComposer 2، وNode.js بإصدار 22.12 أو أحدث، وnpm. ثبّت إضافات PHP المطلوبة، بما فيها PDO SQLite وZIP للإعداد الافتراضي.

## التشغيل

نفّذ الأوامر من مجلد المشروع:

```sh
git clone https://github.com/mansoour/arabic-laravel-saas-starter-kit.git
cd arabic-laravel-saas-starter-kit
composer run setup
php artisan storage:link
composer run dev
```

افتح **http://127.0.0.1:8017**. ينشئ أمر الإعداد ملف البيئة وقاعدة SQLite فارغة عند الحاجة، ويولّد مفتاح التطبيق ويشغّل الترحيلات والبيانات الأولية ويبني ملفات الواجهة. لا يغيّر مفتاح تطبيق موجود. يشغّل أمر التطوير الخادم وعامل الطابور والمجدول وVite على المنفذ 5177.

في Windows، تأكد من اختيار نسخ PHP وNode المتوافقة ضمن `PATH`. يمكن استدعاء PHP مباشرة، مثل `C:\php\php.exe artisan serve --host=127.0.0.1 --port=8017`. يجب أن يكون مجلد العمل هو مجلد المشروع.

## إنشاء حساب الإدارة الأول

1. أنشئ حسابًا من `/register`.
2. أبقِ عامل الطابور قيد التشغيل. تُكتب رسائل البريد محليًا في `storage/logs/laravel.log`؛ افتح رابط التحقق من السجل.
3. عيّن حسابك مالكًا للموقع:

```sh
php artisan starter:owner you@example.com
```

4. سجّل الدخول وافتح `/admin`.

لا توجد حسابات أو كلمات مرور افتراضية. اشتراط المصادقة الثنائية لفريق الإدارة معطّل افتراضيًا، ويمكن تفعيله من إعدادات الأمان. تستمر الحسابات التي فعّلت المصادقة الثنائية في استخدامها عند الدخول.

## قاعدة البيانات والمحتوى

يتضمن المستودع **الترحيلات والمصانع والبيانات الأولية المحايدة** اللازمة لإنشاء قاعدة جديدة. لا يتضمن قاعدة بيانات مستخدمة أو حسابات أو مفاتيح أو ملفات مرفوعة أو محتوى تثبيت فعليًا. ينشئ الإعداد قاعدة SQLite، ويمكن اختيار محرك آخر من ملف `.env` ثم تشغيل `php artisan starter:install`.

الصفحات القانونية والمحتوى الأولي أمثلة يجب مراجعتها واستبدالها قبل النشر. إعادة تشغيل البيانات الأولية تضيف الأدوار والسجلات والصلاحيات الافتراضية؛ لا تنشئ حساب مالك.

تُستبعد ملفات البيئة وقواعد البيانات والنسخ الاحتياطية والسجلات والملفات المرفوعة وتعليمات مساحة العمل من Git. احتفظ بمفتاح التطبيق وكلمات مرور الأرشيف في مكان آمن خارج المستودع.
