# نظام متابعة الحضور والغياب المدرسي

منصة عربية (مع دعم الإنجليزية) لمتابعة الحضور والغياب اليومي في المدارس، مبنية بـ Laravel. تربط منسوبات المدرسة بأولياء الأمور: تحضير يومي لكل فصل، متابعة الغياب والتأخر، أعذار إلكترونية، ملاحظات الطالبات، التواصل مع أولياء الأمور عبر واتساب والاتصال والبريد، إشعارات قابلة للتخصيص، سجل كامل للإجراءات، وتقارير قابلة للتصدير.

[English](README.md) · [الإعدادات](docs/CONFIGURATION.md) · [التكاملات](docs/INTEGRATIONS.md) · [النشر والنسخ الاحتياطي](docs/DEPLOYMENT.md)

## الأدوار

| الدور | المهام الرئيسية |
| --- | --- |
| مدير النظام | تحكم كامل: جميع المدارس والبيانات والتحضير والمنسوبات وإعدادات النظام وقواعد الإشعارات |
| مديرة المدرسة | إدارة المدرسة بالكامل: حسابات المنسوبات، الصفوف والفصول، الطالبات، التحضير، الأعذار، التقارير وسجل الإجراءات |
| الوكيلة | متابعة الغياب والتحضير ومراجعة الأعذار والتواصل مع أولياء الأمور والملاحظات والتقارير، دون إدارة المنسوبات أو هيكل المدرسة |
| شؤون الطالبات | إدارة الصفوف والفصول، والطالبات (إضافة وتعديل وحذف وتوزيع على الفصول واستيراد Excel)، والتحضير اليومي، والأعذار، والتواصل |
| الموجهة الصحية | عرض الغياب، إضافة الأعذار ومراجعتها، الملاحظات الصحية |
| الموجهة الطلابية | متابعة أسباب الغياب، الملاحظات الإرشادية والخطط، التواصل مع أولياء الأمور والتقارير |
| ولي الأمر | متابعة حضور الأبناء، إرسال الأعذار مع المرفقات، الاطلاع على الملاحظات والإشعارات |

تُضاف الصلاحيات الافتراضية مرة واحدة ويمكن تعديلها من **إعدادات النظام ← الأدوار**. تُطبق الصلاحيات على الخادم، وتقتصر بيانات كل مستخدم على مدرسته.

## المزايا

**المتابعة اليومية**
- **لوحة تحكم حسب الدور**: لكل دور واجهته الخاصة مع ترحيب ملوّن وأرقام اليوم.
  - مدير النظام ومديرة المدرسة والوكيلة: بطاقات الأدوار، إحصائيات الغياب الشهرية حسب الفصل والصف، أحدث التنبيهات.
  - شؤون الطالبات: الفصول التي لم تُحضَّر بعد، وإجراءات سريعة (التحضير، الطالبات، الاستيراد، اعتماد أولياء الأمور، الطالبات بدون فصل).
  - الموجهة الصحية: الأعذار بانتظار المراجعة (الطبية أولًا) وأحدث الملاحظات الصحية.
  - الموجهة الطلابية: الطالبات الأكثر غيابًا خلال 30 يومًا وأحدث الملاحظات الإرشادية.
  - ولي الأمر: ينتقل مباشرة إلى بوابة أبنائه.
- **الأسبوع الدراسي السعودي**: يُسجل الحضور من الأحد إلى الخميس فقط. لا يمكن حفظ الحضور يومي الجمعة والسبت، وعند فتح الصفحات اليومية في عطلة نهاية الأسبوع يُعرض آخر يوم دراسي (الخميس). تُضبط أيام الدراسة من `config/school.php`.
- **التاريخ الهجري أولًا**: تظهر جميع التواريخ بالتقويم الهجري (أم القرى) مع التاريخ الميلادي بجانبه، بما في ذلك حقول اختيار التاريخ ورسائل أولياء الأمور والإشعارات وملفات Excel وPDF.
- **قائمة جانبية مقسّمة** لكل الأدوار: لوحة التحكم، الحضور والغياب، المتابعة والتواصل، التقارير، إدارة المدرسة، حسابي، وإعدادات النظام لمدير النظام، ويرى كل مستخدم ما تسمح به صلاحياته فقط.
- **متابعة الغياب**: حالة تحضير كل فصل لأي تاريخ مع قائمة الغائبات والمتأخرات وحالة أعذارهن.
- **تحضير الفصول**: شاشة واحدة لكل فصل (حاضرة، غائبة، متأخرة مع الدقائق، غياب بعذر، ملاحظة). التحضير يومي وليس لكل حصة، والفصل هو شعبة من الصف (أ، ب، ج…).
- **الأعذار**: يرسل ولي الأمر العذر إلكترونيًا مع مرفق اختياري، وتراجعه المختصة بالقبول أو الرفض، أو تسجل عذرًا ورد للمدرسة. قبول العذر يحوّل اليوم إلى غياب بعذر.
- **ملاحظات الطالبات**: عامة، صحية، إرشادية، سلوكية ومواظبة، مع إمكانية مشاركتها مع ولي الأمر.
- **التواصل مع أولياء الأمور**: الغائبات والمتأخرات حسب التاريخ والصف والفصل مع أزرار واتساب (برسالة جاهزة) والاتصال والبريد، ويُوثّق كل تواصل في ملف الطالبة.
- **التقارير والإحصائيات**: تصفية بالفترة والصف والفصل، نسب الغياب، الاتجاه اليومي، الأكثر غيابًا، وجدول الفصول، مع التصدير إلى **Excel** و**PDF عربي** أو الطباعة.

**إدارة المدرسة**
- مدارس متعددة مع إمكانية التبديل بينها لمدير النظام.
- الصفوف (المرحلة والترتيب) والفصول (إضافة عدة شعب دفعة واحدة، السعة، المشرفة).
- بيانات الطالبة: الاسم، رقم الهوية، البريد، الجوال، واسم ولي الأمر وجواله وبريده وصلة القرابة؛ نقل جماعي بين الفصول؛ **استيراد من Excel/CSV** بعناوين عربية أو إنجليزية مع نموذج قابل للتنزيل.
- إنشاء حسابات المنسوبات من مديرة المدرسة أو مدير النظام، مع إرسال رابط تعيين كلمة المرور وإمكانية إيقاف الحساب.
- إعدادات المدرسة وسجل إجراءات المدرسة.

**أولياء الأمور**
- صفحة رئيسية عامة واحدة لتسجيل الدخول وتسجيل ولي الأمر.
- يُدخل ولي الأمر اسمه وبريده وجواله وصلة القرابة وبيانات الطالبة. يحدد مدير النظام طريقة التحقق: رقم الهوية والاسم، أو رقم الهوية وجوال الطالبة، أو الثلاثة معًا، مع توحيد اختلافات الكتابة العربية عند المطابقة.
- يُفعَّل الربط بعد تأكيد البريد (أو بعد اعتماد المدرسة عند تفعيل ذلك)، وتُستكمل بيانات ولي الأمر الناقصة في سجل الطالبة تلقائيًا.
- يمكن لولي الأمر إضافة أبناء آخرين من بوابته.

**الإشعارات**: داخل المنصة وبالبريد، ويُضبط كل حدث من **إعدادات النظام ← إشعارات المدرسة** (تفعيل، داخل المنصة، بريد، الأدوار المستلمة): الغياب والتأخر، العذر الجديد، نتيجة مراجعة العذر، الملاحظات المشاركة، تسجيل ولي أمر جديد واعتماد الربط، وتكرار الغياب حسب حد قابل للتعديل.

**سجل الإجراءات**: يُوثّق كل إنشاء وتعديل وحذف للمدارس والصفوف والفصول والطالبات والحضور والأعذار والملاحظات وسجل التواصل، إضافة إلى الاستيراد والتصدير وتغييرات الحسابات والأدوار.

### أساس المنصة

متاح ضمن **إعدادات النظام**: الواجهات العربية والإنجليزية، التسجيل والتحقق من البريد واستعادة كلمة المرور، المصادقة الثنائية الاختيارية، الأدوار والصلاحيات، الهوية البصرية والمظهر الداكن، محرر الترجمة، الصفحات (ومنها صفحة من نحن)، إشعارات الموقع، قوالب البريد، صندوق الدعم، سجل النشاط، فحوص النظام، تكاملات Resend وGemini وreCAPTCHA وCloudflare R2، الطوابير والجدولة والنسخ الاحتياطي المشفر.

أُزيلت أجزاء الأساس الخاصة بمنصات الاشتراكات والتي لا تحتاجها المدرسة (الباقات والاشتراكات والأسعار ومساحة الأعضاء المنفصلة).

## عن المنصة

**فكرة المنصة وابتكارها:** أ. عزيزة محمد عبدالله القرني · **المدرسة:** مدرسة الابتدائية الخامسة عشرة والمتوسطة السابعة · **مديرة المدرسة:** أ. صالحة حجلاء

## التشغيل

```sh
git clone https://github.com/mansoour/school-attendance-system.git
cd school-attendance-system
composer run setup
php artisan storage:link
composer run dev
```

افتح **http://127.0.0.1:8017**. يتطلب المشروع PHP 8.3 أو أحدث (مع إضافات SQLite وZIP وGD وmbstring وXML) وNode.js 22.12 أو أحدث.

في Windows، يمكن استدعاء PHP مباشرة، مثل `C:\php\php.exe artisan serve --host=127.0.0.1 --port=8017`.

## الخطوات الأولى

1. أنشئ حساب مدير النظام، وسيصله رابط تعيين كلمة المرور (محليًا يُكتب البريد في `storage/logs/laravel.log` مع تشغيل عامل الطابور):

   ```sh
   php artisan school:admin admin@example.com --name="مدير النظام"
   ```

2. سجّل الدخول وأضف المدرسة من **المدارس** (أو نفّذ `php artisan school:demo` لإنشاء مدرسة تجريبية ببيانات وهمية).
3. أضف الصفوف والفصول ثم أضف الطالبات أو استوردهن من Excel.
4. أنشئ حسابات مديرة المدرسة والمنسوبات من **المنسوبات**.
5. راجع **إشعارات المدرسة** و**تسجيل ولي الأمر** في إعدادات النظام.
6. يسجل أولياء الأمور من الصفحة الرئيسية ببيانات أبنائهم.

لا توجد حسابات أو كلمات مرور افتراضية، ولا يتضمن المستودع أي بيانات طالبات.

## النشر على الخادم

1. الخادم: PHP 8.3 أو أحدث (مع PDO وZIP وGD وintl وmbstring وXML)، وComposer، وNode 22.12 للبناء، وشهادة HTTPS، ويشير جذر الموقع إلى مجلد `public/`.
2. `composer install --no-dev --optimize-autoloader && npm ci && npm run build`
3. ملف `.env`: `APP_ENV=production` و`APP_DEBUG=false` و`APP_URL=https://your-domain` و`APP_LOCALE=ar` و`APP_TIMEZONE=Asia/Riyadh` ومفتاح جديد (`php artisan key:generate`) وقاعدة البيانات، ومزود بريد فعلي (مثل Resend: نطاق موثّق ومفتاح API من **إعدادات النظام ← التكاملات** ثم `MAIL_MAILER=resend`).
4. `php artisan starter:install` للتثبيت الجديد، أو `php artisan migrate --force` للتحديث بعد أخذ نسخة احتياطية، ثم `php artisan storage:link`.
5. `php artisan optimize` بعد كل تحديث، ثم `php artisan queue:restart`.
6. تشغيل `php artisan queue:work --tries=3 --timeout=90` بشكل دائم عبر مدير عمليات (الإشعارات والبريد تعمل عبر الطابور)، وتشغيل `php artisan schedule:run` كل دقيقة عبر cron.
7. `php artisan school:admin you@your-domain` لإنشاء حساب مدير النظام، ثم إضافة المدرسة والصفوف والفصول والطالبات والمنسوبات.

جاهز افتراضيًا: جميع إشعارات المدرسة مفعّلة (داخل المنصة وبالبريد)، وقوالب بريد عربية وإنجليزية قابلة للتعديل لكل حدث (**إعدادات النظام ← قوالب البريد الإلكتروني**)، وإشعار ترحيبي مفعّل في الموقع (**إشعارات الموقع**)، وصفحات المساعدة والخصوصية والشروط ومن نحن مكتملة.
